**Project: Proof of Concept (POC) - Automobile Information Retrieval Using RAG Pipelines**

- This project explores two implementations  of a Retrieval-Augmented Generation(RAG) pipelines designed to answer user queries based on automobile related information extracted from pdf files.
- Designed and implemented two RAG pipelines using LangChain and LlamaIndex frameworks to answer user queries based on the contents of PDF files.
- Designed effective prompt engineering techniques to optimize responses from OpenAI LLMs, ensuring high accuracy and relevance in query-answering workflows.
- Evaluated both implementations using the RAGAS framework to measure metrics like faithfulness, answer relevancy, context recall, and precision.
- Integrated OpenAI LLMs with Chroma vector database and Hugging Face embeddings to enable efficient context retrieval and accurate response generation.
- Developed robust retrieval mechanisms to extract relevant context for each query, optimizing the pipelines for performance and accuracy.
- Processed retrieved context through the LLM to deliver precise, context-aware answers to user queries.
- Implemented a RAG application using the AutoGen Agentic AI framework, exploring alternative methodologies for RAG pipelines.
